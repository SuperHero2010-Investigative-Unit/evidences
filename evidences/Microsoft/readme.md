## Key Findings

### Paywalls Everywhere

Too many Microsoft applications require purchasing for full usage. The free tier is crippled. The paid tier is expensive. Students cannot afford it. Low-income users cannot afford it. Freelancers cannot afford it. Small businesses cannot afford it. Families cannot afford it. Seniors cannot afford it. The unemployed cannot afford it.

| Application | Free Tier | Paid Tier |
|-------------|-----------|-----------|
| Windows | Basic | Pro, Enterprise |
| Office | Web only | Microsoft 365 |
| Copilot | Limited | Copilot Pro |
| OneDrive | 5GB | 100GB+ |
| Teams | Basic | Premium |
| Defender | Basic | Defender for Individuals |
| GitHub Copilot | Limited | $10/month |
| Xbox Game Pass | None | $10-17/month |
| LinkedIn Premium | Basic | $30-80/month |
| Azure | Limited | Pay-as-you-go |

### Activation Traps

Users have used Windows for almost 2 years. The free Microsoft Office doesn't allow use without repairing the activated key. Users are forced to uninstall it and use WPS Office instead. Microsoft loses a user. WPS Office gains one. The pattern continues.

### Forced Migration

Users are forced from free to paid. They are forced from local accounts to Microsoft accounts. They are forced from perpetual licenses to subscriptions. They are forced from their own choices to Microsoft's choices.

### Ads in Paid Products

Ads appear in Windows, Office, and other paid products. Users pay for the product and still see ads. This is not acceptable.

### Data Collection

Microsoft collects vast amounts of user data. Telemetry. AI training. Privacy violations. Users cannot opt out meaningfully. Consent is not meaningful.

### Support Failures

Microsoft support is widely criticized as useless. Users report receiving identical AI-generated responses. Tickets are ignored for months.
