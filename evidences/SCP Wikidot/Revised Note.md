# Revised Note: Case 12 — SCP Wikidot

## Overview

This document summarizes the revisions made to Case 12 (SCP Wikidot) after the initial investigation. The revisions were necessary to ensure the accuracy of the evidence and to maintain the credibility of the SuperHero2010 Investigative Unit.

---

## What Was Changed

### 1. False Claims Removed

| False Claim | Why It Was Removed |
| :--- | :--- |
| **"Custom classes are banned by a written rule"** | The SCP Wikidot has no written rule banning custom classes. The rejection is enforced by community consensus and formatting standards, not a hard rule |
| **"-EX suffix is a hard written rule"** | There is no written Site Rule that mandates the -EX suffix. It is a formatting standard enforced by staff and the community, not a codified rule |

### 2. Gaps Fixed

| Gap | How It Was Fixed |
| :--- | :--- |
| **Enforcement mechanism not explained** | Clarified that custom classes are rejected through community voting and formatting standards, not a hard rule |
| **-EX enforcement not explained** | Clarified that the -EX suffix is enforced through formatting standards and community consensus, not a written rule |
| **"Neutralized (De Facto)" example not explained** | Clarified that the class is rejected because it appears redundant to the community, regardless of the author's intent |
| **The "About" page analysis was incomplete** | Added a section contrasting the page's marketing claims with the reality of the wiki's strict rules |
