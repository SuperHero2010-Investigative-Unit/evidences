## 2. Primary Classes

| Class | Definition | Locked Box Test |
|-------|------------|-----------------|
| **Safe** | Easily and safely contained | Lock it in a box, leave it alone, nothing bad will happen |
| **Euclid** | Requires more resources, containment not always reliable | Lock it in a box, leave it alone, not sure what will happen |
| **Keter** | Exceedingly difficult to contain, procedures are extensive | Lock it in a box, leave it alone, it easily escapes |
| **Thaumiel** | Used to contain other SCPs | It's the box |

**Key Note:** Danger doesn't determine class, containment difficulty does.

| Example | Lesson |
|---------|--------|
| **Button that destroys the universe** | Safe, because it can be locked in a box |
| **Cat that randomly switches places** | Keter, because it's difficult to contain |

## 5. The Locked Box Test

The Locked Box Test is the informal guideline for determining class:

| Scenario | Class |
|----------|-------|
| Lock it in a box, leave it alone, nothing bad happens | Safe |
| Lock it in a box, leave it alone, not sure what will happen | Euclid |
| Lock it in a box, leave it alone, it easily escapes | Keter |
| It's the box | Thaumiel |

**Special Considerations:**
- Autonomous, alive, or sapient entities are **almost always Euclid** at minimum.
- Danger doesn't affect class, only containment difficulty.

## 7. Observations

| Observation | Note |
|-------------|------|
| **Class is about containment, not danger** | A universe-destroying button can be Safe |
| **Autonomous entities are Euclid** | Sapience = unpredictability |
| **Neutralized is for dead/disabled SCPs** | Not for "left alone" |
| **Explained is for understood SCPs** | Requires scientific understanding |
| **Archon/Cernunnos allow "choose not to contain"** | But they are secondary classes |

| Aspect | Assessment |

| **Consistency** | The system is internally consistent |

---

## 9. Conclusion

The Object Classes page defines a clear, flexible system for classifying anomalies. The system is based on **containment difficulty**, not danger. The Locked Box Test provides a simple guideline for determining class. Secondary and esoteric classes allow for narrative flexibility.

**Key takeaway:** An SCP's class is about how hard it's to contain, not how dangerous it's. This is the Foundation's fundamental logic.
