# Everything is BROKEN

## 1. Overview

The SCP Wikidot presents itself as a curated, professional, and functional platform. It presents itself as a community. It presents itself as a system that works.

It doesn't work.

The SCP Wikidot is broken. Not now. Not after years of use. From the very beginning. The rules were flawed. The system was flawed. The structure was flawed. But no one recognized it. No one acknowledged it. No one fixed it.

And so it remains broken.

---

## 2. What Is Broken

### The Rules

| Problem | Explanation |
|---------|-------------|
| **Too strict** | No flexibility, no exceptions |
| **Too vague** | "Don't be a dick" is subjective |
| **Too subjective** | Staff discretion is unchecked |
| **Too rigid** | Custom classes prohibited |
| **Too redundant** | -EX suffix required |

### The Object Classes

| Problem | Explanation |
|---------|-------------|
| **Rigid** | No custom classes allowed |
| **Redundant** | -EX suffix adds nothing |
| **Incomplete** | Many anomalies don't fit |
| **Controlling** | Creativity is stifled |

### The Deletion System

| Problem | Explanation |
|---------|-------------|
| **Brutal** | Articles deleted at -10 |
| **Punitive** | No chance to improve |
| **Inconsistent** | Staff can delete for any reason |
| **Discouraging** | New authors are driven away |

### The Staff Authority

| Problem | Explanation |
|---------|-------------|
| **Unchecked** | Staff decisions are final |
| **Subjective** | Rules are interpreted unevenly |
| **Unaccountable** | Appeals are limited |
| **Authoritarian** | Dissent is silenced |

### The Membership

| Problem | Explanation |
|---------|-------------|
| **Exclusionary** | 18+ only, no exceptions |
| **Restrictive** | Strict username policy |
| **Fear-based** | AI ban is absolute |
| **Hostile** | High barrier to entry |

### The Canon

| Problem | Explanation |
|---------|-------------|
| **Conflicting** | Many origins, no single canon |
| **Confusing** | Readers don't know what is true |
| **Unresolved** | No one decides what is official |
| **Chaotic** | SCP-001 has too many variants |

### The Internal Wars

| Problem | Explanation |
|---------|-------------|
| **Prohibited** | The Foundation must appear unified |
| **Unrealistic** | Real organizations fracture |
| **Limiting** | Narrative complexity is prevented |
| **Controlling** | The Foundation can't be challenged |

### The Criticism Policy

| Problem | Explanation |
|---------|-------------|
| **Subjective** | Staff decide what is acceptable |
| **Enforced** | Users can't self-enforce |
| **Limited** | Dissent is discouraged |
| **Controlled** | Feedback is monitored |

### The Community

| Problem | Explanation |
|---------|-------------|
| **Judgmental** | Articles are downvoted quickly |
| **Exclusionary** | New authors are driven away |
| **Hostile** | Staff punish dissent |
| **Broken** | The system doesn't work |
