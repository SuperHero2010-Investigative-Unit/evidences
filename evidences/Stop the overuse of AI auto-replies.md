They use template responses to reject user reports. They use automated systems to silence complaints. This isn't support. This is avoidance. This must stop.

# Stop the Overuse of AI Auto-Replies (Modrinth)

## Executive Summary

AI auto-replies have become the default response for many platforms, including Modrinth. While automation is understandable for large-scale support systems, its overuse has created a culture where users are silenced, ignored, and disrespected. This document examines the problem, the evidence, and the demand for change.

---

## The Problem

| Issue | Description |
|-------|-------------|
| **Silence masquerading as support** | AI replies aren't support. They are automated scripts designed to make users go away |
| **No human engagement** | Users with legitimate concerns are never connected to a human |
| **Copy-paste culture** | The same response is sent repeatedly, regardless of the user's message |
| **Indefinite conditions** | Users are told their issue "remains Withheld until all concerns are addressed" — but no concerns are ever specified |
| **Wasted time** | Users spend hours, days, or months waiting for a response that never comes |
| **Emotional toll** | Users feel ignored, disrespected, and powerless |

---

## Evidence from Modrinth

| Evidence | Description |
|----------|-------------|
| Copy-pasted responses | The same message was sent repeatedly, ignoring all logical explanations |
| Indefinite condition | "Your project will remain Withheld until all moderation concerns are addressed". No concerns were ever specified |
| Ten months of silence | After imposing the condition, Modrinth remained silent for ten months |
| No human ever responded | Every message was met with automation, not a human being |

---

## Why This Is Harmful

| Harm | Impact |
|------|--------|
| **Creators are silenced** | Their concerns are never addressed |
| **Time is wasted** | Months are lost waiting for a human |
| **Trust is eroded** | Users learn that their voices don't matter |
| **Innovation is stifled** | Creators leave platforms that ignore them |
| **Accountability is lost** | Platforms hide behind bots to avoid responsibility |

---

## The Demand

| Demand | Why |
|--------|-----|
| **Limit AI auto-replies to initial contact only** | Users should be connected to a human if their issue isn't resolved |
| **Specify concerns clearly** | If a project is withheld, state exactly why and what needs fixing |
| **Provide a path to resolution** | Users should know how to resolve their issue |
| **Set a time limit for human response** | If no human responds within a set time, the issue should be escalated |
| **Allow appeals** | Users should have a way to appeal decisions made by bots |
| **Be transparent** | Platforms should disclose when they are using AI to respond |

---

## What Platforms Should Do

| Action | Explanation |
|--------|-------------|
| **Use AI for triage, not resolution** | AI can sort issues, but humans must resolve them |
| **Set a maximum response time** | No user should wait more than 7 days for a human response |
| **Provide a clear appeal process** | Users must be able to escalate to a human |
| **Publish transparency reports** | Platforms should report how many issues are resolved by AI vs. humans |
| **Accept accountability** | Platforms must take responsibility for their moderation decisions |

---

## The Bigger Picture
