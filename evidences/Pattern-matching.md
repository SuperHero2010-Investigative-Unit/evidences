# Pattern-matching: The Root Cause of AI Code Corruption 

---

## 1. Definition

**Pattern-matching** is the method AI coding tools use to find and replace code based on pre-made templates (patterns). It DOESN'T understand what the code does, it only knows how code "usually looks".

> *"Pattern-matching isn't understanding. It's guessing based on memorized patterns."*

---

## 2. The Problem with Haxe

| Issue | Explanation |
|-------|-------------|
| **Patterns are for JS/TS, not Haxe** | Haxe is an uncommon language. AI lacks sufficient training data |
| **No understanding of Haxe syntax** | AI guesses based on other languages |
| **Coordinate replacement errors** | AI replaces code at the WRONG position |
| **Corrupted structures** | Missing braces, broken indentation, deleted logic |

> *"Pattern-matching works great for JavaScript, TypeScript, and Python. But it fails for Haxe."*

---

## 3. Forensic Evidence

### Original Code (Haxe, valid):

```haxe
function ready(a:Float):Bool {
    if (a % 2 != 0) return false;
    return true;
}
public var a:Float = 1;
if ready(a) trace("Ready");
else trace("Not ready yet");
```

### After Pattern-Matching (Windsurf):

```haxe
function ready(a:Float):Bool {
    if (a % 2 != 0) return false;
    return true;

if ready(a) {
    trace("Ready");
    trace("Go!");
} else trace("Not ready yet");
```

### Damage:

| # | Damage | Severity |
|---|--------|----------|
| 1 | Code INJECTED inside function | High |
| 2 | Missing `}` → can't compile | High |
| 3 | Unintended `trace("Go!")` added | Medium |
| 4 | Else branch inserted where none existed | Medium |

> *"The AI didn't understand the code. It only saw a pattern and replaced it at the wrong position."*

---

## 4. Why Pattern-Matching Fails

| Reason | Explanation |
|--------|-------------|
| **No semantic understanding** | AI doesn't know what code does, only what it looks like |
| **Wrong coordinate** | Replaces at the first pattern match, not the right location |
| **Structural damage** | Deletes working code, misses closing braces |
| **Logic change** | Adds unnecessary code, changes behavior |

> *"Pattern-matching is like a surgeon who operates on a healthy bone because it looked 'similar' to a broken one."*

---

## 5. The Coordinate Killer

The most dangerous aspect of pattern-matching is **coordinate replacement error**:

| Step | What AI Does | Result |
|------|--------------|--------|
| 1 | Scans code for pattern | Finds similar-looking code |
| 2 | Determines position to replace | **Wrong position** |
| 3 | Replaces code | Code corrupted |

> *"Pattern-matching doesn't read code. It guesses coordinates."*
