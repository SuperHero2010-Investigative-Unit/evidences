## Key Findings

### 1. Terms of Service: A Trap

| Issue | My Concern |
|-------|------------|
| **Broad License** | Users grant Meta a worldwide, perpetual license to their content |
| **Use of Likeness** | Meta can use users' names and faces for advertising without compensation |
| **Zero Liability Cap** | Meta disclaims all liability |
| **Indemnification** | Users must defend Meta against claims |
| **Unilateral Changes** | Meta can change terms without meaningful consent |

### 2. Privacy Policy: A Surveillance Tool

| Issue | My Concern |
|-------|------------|
| **Vast Data Collection** | Posts, photos, messages, location, device data, biometric information |
| **Targeted Advertising** | User data is used for advertising without meaningful consent |
| **AI Training** | User content is used to train AI without compensation |
| **Data Sharing** | Data is shared with third parties |
| **No Real Opt-Out** | Users can't opt out of data collection |

### 3. Moderation: Arbitrary and Punitive

| Issue | My Concern |
|-------|------------|
| **AI Context Blindness** | Automated systems make decisions without understanding nuance |
| **Inconsistent Enforcement** | Policies are applied arbitrarily |
| **Weak Appeals** | Appeals are slow, often automated, and paywalled |

### 4. Termination: Final and Absolute

| Issue | My Concern |
|-------|------------|
| **No Warning** | Accounts can be terminated without prior notice |
| **Permanent Data Loss** | All content is deleted permanently |
| **Paywalled Appeals** | Non-paying users have no recourse |

### 5. Paywalled Appeals: A Protection Racket

| Issue | My Concern |
|-------|------------|
| **No Universal Right to Appeal** | Appeals are only available to paying users |
| **Discrimination** | Non-paying users are treated as second-class citizens |
| **Profiting from Disputes** | Meta profits from users who need to appeal |
